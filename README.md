# CheckPoint 2 - Lista de Compras

Projeto desenvolvido para a disciplina de Cross-Platform Application Development.

O objetivo do projeto é criar uma lista de compras simples utilizando React Native e Expo.

## Funcionalidades

- Digitar um item no campo de texto
- Adicionar o item na lista
- Exibir os itens utilizando FlatList
- Utilizar useState para armazenar os itens

## Tecnologias utilizadas

- React Native
- Expo
- useState
- FlatList
- StyleSheet

## Como executar

Abra o projeto no VS Code e, no terminal, execute:

npm install

npx expo start

Depois, escolha onde deseja abrir o aplicativo.

## Prints

A pasta `prints` contém as três telas pedidas no CheckPoint:

1. Lista vazia
2. Lista com 1 item
3. Lista com 5 itens
